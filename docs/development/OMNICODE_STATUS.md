## Baseline

- Architecture: Electron 44 main process + sandboxed React 19 renderer + typed
  CommonJS preload bridge; TypeScript throughout; no Tauri or Rust.
- Build: electron-vite and electron-builder, macOS 14 minimum, separate x64 and
  arm64 DMG/ZIP artifacts, native `node-pty` unpacked from ASAR.
- Git: `master` had no commits at audit start. Stabilization checkpoint
  `28bb077` preserves the verified 0.1.1 state; Work Mode continues on
  `codex/work-mode`. No user changes were discarded.
- Baseline launch: packaged Intel app started on macOS Sonoma without a white
  screen or captured renderer exception. Setup, workspace IPC, real zsh PTY,
  localhost server, and remote-navigation blocking passed the existing smoke.
- Baseline tests: 185 automated tests passed; the native Keychain test was run
  separately and passed. This is evidence for covered paths only.
- Current verification: 392 automated tests passed, one native Keychain test is
  intentionally skipped from the normal run, TypeScript and the production
  build pass. The refreshed packaged Intel app passed dark and compact-light
  Work Mode smokes covering mode separation, persistence, Managed Browser,
  all 13 Gmail and 15 Drive tool registrations, reduced motion, Escape dismissal,
  rapid mode switching, horizontal-overflow bounds, and zero renderer errors.
  A three-launch packaged soak also passed fresh onboarding, workspace startup,
  idle-resource, quit, and child-process cleanup bounds. Existing Intel and Apple
  Silicon 0.2.0 DMG/ZIP artifacts remain the latest installers until the final
  release-candidate packaging step; the refreshed directory package does not
  silently replace those versioned artifacts.
